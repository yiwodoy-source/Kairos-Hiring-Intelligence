# n8n Workflow Setup Guide
## AI-Powered Candidate Sourcing and Personalized Outreach Automation

This guide will help you configure all the necessary connections and credentials for your n8n workflow.

---

## 📋 **Prerequisites Checklist**

Before starting, ensure you have accounts and API access for:

- [ ] **Serper API** (for Google searches)
- [ ] **OpenAI API** (already configured with n8n free credits)
- [ ] **Google Sheets** (for candidate storage)
- [ ] **Gmail** (for sending emails)
- [ ] **LinkedIn** (optional - for job posting)
- [ ] **Twitter/X** (optional - for job posting)
- [ ] **Facebook** (optional - for job posting)
- [ ] **Telegram** (optional - for job posting)

## 🔧 **Step-by-Step Configuration**

### **1. Workflow Configuration Node**

Replace the following placeholders in the "Workflow Configuration" node:

```javascript
serperApiKey: "<YOUR_SERPER_API_KEY>"
companyName: "Nexus HR AI"  // or your company name
recruiterName: "Your Name"   // your name or recruiting team name
```

**How to get Serper API Key:**
1. Go to https://serper.dev/
2. Sign up for a free account (100 free searches)
3. Navigate to API Keys section
4. Copy your API key

---

### **2. Job Input Details Node**

This node contains the job requirements. Update these values each time you run the workflow:

```javascript
role: "Senior Backend Engineer"           // Example: "Senior Full Stack Developer"
skills: "Node.js, AWS, Python"           // Example: "React, TypeScript, Node.js"
experience: "5+"                         // Example: "3-7 years"
location: "Remote"                       // Example: "Bangalore, India" or "Remote"
```

---

### **3. Google Sheets Configuration**

You need to create a Google Sheet and configure two nodes:

#### **A. Create Google Sheet**

1. Go to Google Sheets: https://sheets.google.com
2. Create a new spreadsheet named "Candidate Sourcing Database"
3. Create a sheet named "Candidates" with these columns:

| name | current_role | company | skills | experience_years | profile_url | email | status | email_sent_date |
|------|-------------|---------|--------|------------------|-------------|-------|--------|-----------------|

4. Copy the Sheet ID from the URL:
   - URL format: `https://docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit`
   - Example: `1a2b3c4d5e6f7g8h9i0j`

#### **B. Configure n8n Google Sheets Credentials**

1. In n8n, go to **Credentials** → **Add Credential** → **Google Sheets API**
2. Choose authentication method: **OAuth2**
3. Follow the OAuth flow to authorize n8n to access your Google Sheets
4. Save the credential

#### **C. Update Workflow Nodes**

Replace `<__PLACEHOLDER_VALUE__Google Sheet ID for Candidates__>` in:
- **Store Candidates** node
- **Update Candidate Status** node

With your actual Sheet ID.

---

### **4. Gmail Configuration**

#### **A. Configure Gmail Credentials in n8n**

1. In n8n, go to **Credentials** → **Add Credential** → **Gmail**
2. Choose authentication method: **OAuth2**
3. Follow the OAuth flow to authorize n8n to send emails from your Gmail
4. Save the credential

#### **B. Update Send Email Node**

The "Send Email" node is configured to use:
- **To:** `{{ $json.email }}` (from candidate data)
- **Subject:** `{{ $json.subject }}` (generated by AI)
- **Body:** `{{ $json.body }}` (generated by AI)
- **Sender Name:** Your recruiter name from configuration

**⚠️ IMPORTANT:** The workflow expects candidates to have an `email` field, but the AI Candidate Extractor might not always find emails from public search results. You may need to:

1. **Option A:** Manually add emails to the Google Sheet after candidates are stored
2. **Option B:** Integrate with a service like Hunter.io or Apollo.io to find emails
3. **Option C:** Use LinkedIn InMail instead of email

---

### **5. Social Media Integrations (Optional)**

#### **A. LinkedIn**

1. In n8n, go to **Credentials** → **Add Credential** → **LinkedIn**
2. You'll need to create a LinkedIn App:
   - Go to https://www.linkedin.com/developers/apps
   - Create a new app
   - Get Client ID and Client Secret
   - Add OAuth redirect URL from n8n
3. Configure the credential in n8n

#### **B. Twitter/X**

1. In n8n, go to **Credentials** → **Add Credential** → **Twitter**
2. You'll need Twitter API access:
   - Go to https://developer.twitter.com/
   - Create a new app
   - Get API Key, API Secret, Access Token, Access Token Secret
3. Configure the credential in n8n

#### **C. Facebook**

1. In n8n, go to **Credentials** → **Add Credential** → **Facebook Graph API**
2. You'll need a Facebook App:
   - Go to https://developers.facebook.com/
   - Create a new app
   - Get App ID and App Secret
   - Request necessary permissions for posting
3. Configure the credential in n8n

#### **D. Telegram**

1. Create a Telegram Bot:
   - Open Telegram and search for `@BotFather`
   - Send `/newbot` and follow instructions
   - Copy the Bot Token
2. Get your Channel/Group Chat ID:
   - Add your bot to the channel/group
   - Send a message to the channel
   - Visit: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
   - Find the `chat.id` in the response
3. In n8n, configure Telegram credentials with your Bot Token
4. Update the "Post to Telegram" node:
   - Replace `<__PLACEHOLDER_VALUE__Telegram Channel/Group Chat ID__>` with your actual Chat ID

## ⚠️ **Known Limitations & Recommendations**

### **1. Email Extraction Challenge**

The AI Candidate Extractor relies on publicly available data from Google searches. Email addresses are rarely public, so you'll likely need to:

**Recommended Solution:** Add an email enrichment step

```javascript
// Add a new HTTP Request node after "AI Candidate Extractor"
// Use services like:
// - Hunter.io API: https://hunter.io/api
// - Apollo.io API: https://www.apollo.io/api
// - Snov.io API: https://snov.io/api
```

### **2. Rate Limits**

- **Serper API:** 100 free searches/month (upgrade for more)
- **OpenAI API:** n8n free credits are limited (consider your own API key)
- **Gmail:** 500 emails/day for free accounts, 2000/day for Google Workspace

### **3. Legal Compliance**

⚠️ **IMPORTANT:** Ensure compliance with:
- **GDPR** (if targeting EU candidates)
- **CAN-SPAM Act** (for US email outreach)
- **LinkedIn Terms of Service** (automated posting may violate ToS)
- **Data Privacy Laws** in your jurisdiction

**Best Practices:**
- Only contact candidates who have opted in
- Include unsubscribe links in emails
- Store consent records
- Respect robots.txt and rate limits

## 🔗 **Integration with Your Nexus HR AI Application**

Based on your existing codebase, you can integrate this n8n workflow with your application:

### **Option 1: Webhook Trigger**

Replace the "Manual Trigger" with a "Webhook" node:

```javascript
// In your React app (SourcingView.tsx), trigger the workflow:
const triggerN8nWorkflow = async (jobData) => {
  const response = await fetch('YOUR_N8N_WEBHOOK_URL', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      role: jobData.role,
      skills: jobData.skills,
      experience: jobData.experience,
      location: jobData.location
    })
  });
  return response.json();
};
```

### **Option 2: n8n API Integration**

Use n8n's API to trigger workflows programmatically:

```javascript
// In your backend (Python/FastAPI)
import requests

def trigger_sourcing_workflow(job_id, job_details):
    n8n_api_url = "http://localhost:5678/api/v1/workflows/YOUR_WORKFLOW_ID/execute"
    headers = {"X-N8N-API-KEY": "your-api-key"}
    payload = {
        "role": job_details["role"],
        "skills": job_details["skills"],
        "experience": job_details["experience"],
        "location": job_details["location"]
    }
    response = requests.post(n8n_api_url, json=payload, headers=headers)
    return response.json()
```

### **Option 3: Shared Database**

Store candidates in a shared PostgreSQL database instead of Google Sheets:

1. Replace Google Sheets nodes with PostgreSQL nodes
2. Use the same database as your Nexus HR AI application
3. Candidates will appear directly in your application

## 📊 **Monitoring & Optimization**

### **Track Workflow Performance**

1. **Execution History:** Check n8n's execution history for errors
2. **Success Metrics:**
   - Number of candidates found per search
   - Email open rates (if using email tracking)
   - Response rates from candidates
3. **Cost Tracking:**
   - Serper API usage
   - OpenAI API token consumption

### **Optimization Tips**

1. **Batch Processing:** Process multiple job postings in one execution
2. **Caching:** Cache search results to avoid duplicate API calls
3. **Error Handling:** Add error handling nodes to retry failed operations
4. **Scheduling:** Use n8n's cron trigger to run automatically (e.g., daily)

## 🆘 **Troubleshooting**

### **Common Issues**

| Issue | Solution |
|-------|----------|
| "Serper API authentication failed" | Check if API key is correct and has remaining credits |
| "No candidates extracted" | Search query might be too specific, try broader terms |
| "Gmail send failed" | Check OAuth credentials and daily sending limits |
| "Google Sheets not found" | Verify Sheet ID and ensure n8n has access permissions |
| "OpenAI rate limit" | Upgrade to paid OpenAI plan or reduce request frequency |
